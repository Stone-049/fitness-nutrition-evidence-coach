# 训练知识基线

## 训练变量

| 变量 | 实用规则 |
|---|---|
| 动作选择 | 覆盖蹲、髋铰链、推、拉、提携、旋转与抗旋转 |
| 动作顺序 | 高技能、大重量、主要目标动作优先 |
| 强度 | 力量常用 ≥80% 1RM；增肌可用 30%–85% 1RM |
| 次数 | 增肌约 5–30 次；力量 1–6 次；肌耐力 15+ 次 |
| 组数 | 每肌群每周约 10–20 个有效组 |
| 频率 | 每肌群每周约 2 次便于分配训练量 |
| 休息 | 力量 2–5 分钟；增肌 1–3 分钟 |
| 幅度 | 可控、无痛、尽量完整 |
| 进阶 | 次数、重量、组数、动作质量或节奏逐步增加 |
| 力竭 | 不要求每组力竭；多数正式组 RIR 1–3 |
| 减量 | 每 4–8 周或疲劳积累时降低总量，保留一定强度 |

## 新手模板

- 每周 2–3 次全身训练
- 每次 1 个蹲/腿推、1 个髋铰链、1 个推、1 个拉、1 个核心
- 每个动作 2–3 组，每组 6–12 次
- 保留 2–3 次余力
- 先练技术，再增加重量

## 增肌模板

- 上下肢分化或推拉腿
- 每肌群每周 10–20 组
- 8–15 次为主，穿插 5–8 次和 15–20 次
- 多数正式组 RIR 1–3
- 记录重量、次数和组数

## 力量模板

- 主项 4–6 组，1–6 次，强度 ≥80% 1RM
- 辅助动作 2–4 个，6–10 次
- 主项休息 2–5 分钟
- 4 周板块后减量或重新测试

## 有氧与体能

- 基础目标：每周约 150 分钟中等强度有氧
- 从低冲击、可持续的强度开始
- HIIT 需有基础和恢复，不是新手唯一选择
- 同一天训练时，通常先做高质量力量，再做有氧
