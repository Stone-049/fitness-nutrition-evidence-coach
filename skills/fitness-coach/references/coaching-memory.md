# 持久教练档案与日志

## 使用原则

- 只有用户同意时才持久保存档案。
- 优先保存到用户指定的本地目录或对话可见的状态文件。
- 不采集未提供的身高、体重、疾病、饮食或训练数据。
- 不把自述数据写成客观测量。
- 数据过期时标记“过期”，不要补造。
- 公开输出中去除身份信息和可识别细节。

## 档案结构

```json
{
  "profile": {
    "age_band": "可选，例如 18-29",
    "sex": "可选",
    "height_cm": "可选",
    "weight_kg": "可选",
    "training_experience": "新手/中级/高级",
    "primary_goal": "减脂/增肌/力量/健康/专项",
    "secondary_goals": [],
```

## 训练日志字段

- 日期
- 动作
- 组数
- 重量
- 次数
- RIR/RPE
- 疼痛 0–10
- 动作质量备注
- 训练后 24 小时反应

## 营养日志字段

- 日期
- 总能量
- 蛋白质
- 碳水
- 脂肪
- 体重趋势
- 饥饿和饱腹感
- 依从性
- 胃肠道或特殊情况

## 决策日志

每次重要调整记录：

1. 触发：为什么调整。
2. 观察：使用了哪些数据。
3. 决策：修改了什么。
4. 预期：希望在多久内看到什么变化。
5. 复评：下一次检查日期。

## 周复盘问题

1. 本周完成了多少次训练？
2. 主项重量、次数或动作质量是否进步？
3. 疼痛、睡眠、疲劳和压力如何？
4. 饮食执行和体重趋势如何？
5. 下周只调整一个什么变量？

## 数据质量规则

- 单日体重不构成趋势。
- 单次 HRV 不构成恢复结论。
- 单次疼痛不构成诊断。
- 没有记录时明确说“没有足够数据”。
- 不同设备的数据不混用同一基线。
