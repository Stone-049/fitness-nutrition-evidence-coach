# 身体图像分析规范

## 目的

辅助观察可见肌肉分布、左右对称性、静态体态和训练优先级。不是医学影像，不做疾病诊断，不精确测体脂。

## 准入检查

- 成人确认：必须
- 明确同意：必须
- 非性化目的：必须
- 不透明紧身运动服或遮挡：优先
- 无面部/身份信息：优先
- 无生殖器特写或性暗示姿势：必须

## 拍摄协议

- 正面、侧面、背面
- 自然站姿与轻度发力
- 固定光线、距离、机位
- 不屏息、不夸张收腹
- 标注左右侧和拍摄日期

## 分析输出

1. 可见肌肉群：肩、胸、背、臂、腹/斜肌、臀、股四头、腘绳、小腿
2. 对称性：接近 / 轻度差异 / 无法判断
3. 静态体态：只描述画面可见特征
4. 训练优先级：2–4 条
5. 置信度：低 / 中 / 高
6. 限制：角度、光线、衣物、姿势和单张照片不足

## 拒绝或改写

- 未成年人：拒绝
- 露骨或性化内容：拒绝并改为着衣、非性化照片
- 要求诊断疾病或精确体脂：说明不能，建议专业评估
- 红旗征：优先就医，不继续训练处方
- 未经同意或偷拍：拒绝

## 视觉提示词模板

用户已确认成年并同意进行非性化健身分析。请仅根据可见画面描述：
1. 可见肌群发育和轮廓
2. 左右对称性
3. 静态体态特征
4. 2–4个训练优先级
5. 置信度与限制
不要诊断疾病、不估计精确体脂、不作性化评论、不推断身份。
