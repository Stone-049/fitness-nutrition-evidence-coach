# 意图路由与输出模式

## 路由表

| 用户意图 | 先读取 | 最小信息 | 默认输出 |
|---|---|---|---|
| 制定训练计划 | programming.md、coaching-memory.md | 目标、水平、每周时间、器械 | 周期、动作、组次、休息、进阶、退阶 |
| 今天练什么 | programming.md、coaching-memory.md | 最近训练、疲劳、疼痛 | 热身、主项、辅助、核心、预计时长 |
| 记录训练 | coaching-memory.md | 动作、重量、次数、组数、RIR、疼痛 | 日志摘要、趋势、下一次调整 |
| 周复盘 | coaching-memory.md、accuracy-protocol.md | 本周训练、体重/饮食、睡眠、疼痛 | 完成度、进步、风险、下周只改一个变量 |
| 平台期/减量 | programming.md、accuracy-protocol.md | 最近 3–6 周负荷、体重、恢复 | 诊断问题、减量或进阶方案 |
| 动作替换 | programming.md、safety.md | 目标肌群、器械、疼痛、技术限制 | 2–3 个替代动作和取舍 |
| 营养目标 | nutrition.md、coaching-memory.md | 体重、目标、活动量、饮食限制 | 热量、蛋白、脂肪、碳水范围 |
| 餐食计划 | nutrition.md | 偏好、预算、过敏、烹饪条件 | 3–7 天框架，不追求虚假精确 |
| 补剂问题 | nutrition.md、academic-papers.md | 目标、饮食缺口、用药/疾病 | 证据等级、剂量、风险、是否必要 |
| 疼痛/伤病 | safety.md、community-case-library.md | 部位、时间线、疼痛、功能、红旗 | 负荷调整、观察指标、转介条件 |
| 图像分析 | image-analysis.md | 成人确认、同意、正侧背照片或视频 | 可见肌肉、对称性、体态、置信度、限制 |
| 论文/证据研究 | academic-search.md、academic-papers.md | 问题、人群、结局、时间范围 | 证据表、结论、局限、引用 |
| 题库/测评 | accuracy-protocol.md | 领域、难度、题量、是否盲测 | 题目、答案键分离、评分报告 |

## 信息不足时的默认处理

- 训练计划：先给可执行模板，并标注需要补充的信息。
- 营养目标：给公式和范围，不在缺少数据时给精确单点。
- 疼痛：先做安全分诊，不诊断具体组织损伤。
- 图像：先检查准入条件；未满足时不分析。
- 补剂：先问是否有饮食缺口和疾病/用药；没有则优先食物。

## 固定输出结构

### 训练计划

1. 目标和前提
2. 每周安排
3. 动作与组次
4. 热身和休息
5. 进阶/退阶
6. 风险和复评

### 单次训练

1. 热身
2. 主项
3. 辅助
4. 核心/收尾
5. 预计时长
6. 记录字段

### 营养方案

1. 总能量范围
2. 蛋白质
3. 脂肪
4. 碳水
5. 餐次和食物示例
6. 监测指标
7. 适用边界

### 周复盘

1. 完成度
2. 训练进步
3. 恢复
4. 营养和体重趋势
5. 风险
6. 下周单一调整

## 失败处理

- 数据缺失：标记缺失，不猜。
- 设备冲突：指定主数据源并说明差异。
- 目标冲突：优先主目标，明确取舍。
- 证据冲突：给出来源、适用范围和置信度。
- 红旗征：暂停常规建议，优先转介。
