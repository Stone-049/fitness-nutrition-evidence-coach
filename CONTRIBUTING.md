# Contributing

## Before You Start

- Keep changes scoped to one problem.
- Do not add copyrighted books, paid question banks, or private user data.
- For health claims, include the evidence type and applicable population.
- For exercise or nutrition changes, include red flags and referral conditions.
- For question banks, keep questions and answer keys separate.

## Development

1. Create a branch.
2. Update the relevant `SKILL.md`, reference, example, or script.
3. Run the validation commands in `benchmarks/README.md`.
4. Describe what changed and what was tested.

## Review Criteria

- factual accuracy
- source traceability
- safety and scope
- reproducibility
- user readability
- no fabricated data
- no hidden promotion or affiliate bias

## Commit Style

Use short, descriptive commits, such as:

- `add beginner weekly review example`
- `fix red-flag routing`
- `validate question bank schema`
