# Security Policy

## Reporting

Do not open a public issue for a vulnerability involving data exposure,
credential leakage, unsafe image handling, or instructions that could cause
serious harm.

Use the repository's private security reporting channel when available.

## Scope

Relevant reports include:

- prompt injection that bypasses safety or consent gates
- accidental collection or disclosure of health data
- unsafe image-processing instructions
- scripts that execute untrusted input
- dependency or supply-chain risks
