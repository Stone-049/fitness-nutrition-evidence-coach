# Awesome Fitness Agent Skills

A curated reference list of **100 GitHub Skills** relevant to fitness, nutrition, health research, coaching, and Skill engineering.

Read the full catalog in [100-skill-catalog.md](100-skill-catalog.md).

## Why this list exists

Most fitness Agent projects implement only one piece:

- workout generation
- persistent coaching memory
- nutrition calculation
- readiness/wearable data
- research and citation
- document generation
- evaluation

This catalog documents the patterns we studied before expanding Fitness Nutrition Evidence Coach.

## Scope

- 45 core fitness/nutrition Skills
- 30 health/research-adjacent Skills
- 25 engineering/delivery support Skills

The list is intentionally not described as 100 fitness-specific Skills.
